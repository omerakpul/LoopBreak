# Bundled fonts

All fonts are licensed under the SIL Open Font License 1.1 (see the OFL-*.txt files) and are
bundled in `app/src/main/res/font` so the app works offline and needs no network permission.

| Font | Used for | Source |
|---|---|---|
| Space Grotesk | Titles, headings and the large score numbers | https://fonts.google.com/specimen/Space+Grotesk |
| Inter | Body text and labels | https://fonts.google.com/specimen/Inter |
| JetBrains Mono | Timestamps in the raw events screen | https://fonts.google.com/specimen/JetBrains+Mono |
